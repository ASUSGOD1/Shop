# Shop
# ⚡ 闪电卡网 | 自动发卡系统（开源版）

一个轻量级 Node.js + SQLite 购物卡网，用于虚拟商品自动发卡。适合数字商品、激活码、礼品卡等交易。

## ✨ 特性

- 🛍️ 商品展示、实时库存
- 💳 购买即生成订单及卡密（自动发卡）
- 📦 内置 SQLite 数据库，无需额外配置
- 🔄 RESTful API，前后端分离架构
- 🎨 响应式设计，移动友好
- 🧩 方便二次开发和部署

## 📦 技术栈

- Node.js + Express
- SQLite3
- HTML5/CSS3/原生 JavaScript
